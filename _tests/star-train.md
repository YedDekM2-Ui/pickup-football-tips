# ฝึกแม่แบบตัวอ่านรูปดวง (web/js/star-tpl.js)

ตัวอ่าน `web/js/star-read.js` เทียบก้อนตัวเลขกับแม่แบบ — มีรูปดวงหน้าตาใหม่เมื่อไหร่ เติมแม่แบบได้แบบนี้

1. เขียนความจริงของรูป (ราศีละดาวอะไร เรียงบน→ล่าง ถ้าช่องเรียงแนวตั้ง ไม่งั้นซ้าย→ขวา) แบบเดียวกับ `fixtures/star-truth-thai.js`
2. เปิดรูปใน Chrome จริง (headless) แล้วเก็บ `srFeat_` ของทุกก้อนพร้อมป้าย — **ต้องถอดภาพด้วยเบราว์เซอร์** ไม่ใช่ jpeg-js (ถอดต่างกันนิดเดียวก็พอให้เลขกลางดวงอ่านผิด)
3. รวมกับแม่แบบเดิม ตัดตัวที่ห่างกัน < 0.8 ทิ้ง (ห้ามตัดด้วย "N ตัวแรกต่อป้าย" — เลขไทย ๕ กับเลขอารบิก 5 ใช้ป้ายเดียวกัน เลขกลางดวงจะหายหมด)
4. วัดแบบปิดรูปทีละใบ (แม่แบบไม่มีรูปนั้น) ต้องอ่านดาวถูกทุกใบ หรือถูกหลังเจ้าของตอบคำถาม

กติกาที่ตัวอ่านใช้: ปรับรูปเป็นกว้าง 870 ก่อนเสมอ · ดาวแต่ละดวงอยู่ได้ที่เดียว (เลขซ้ำ+เลขขาด = แก้ตัวที่เสียน้อยสุด) · ตัวไหนไม่ชัวร์ต้องถามเจ้าของ (เจ้าของสั่ง 16 ต.ค. 69)
