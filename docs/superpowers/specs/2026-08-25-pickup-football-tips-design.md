# Pickup Football Tips — สเปกออกแบบ

วันที่ 25 ส.ค. 2569 · ผู้ใช้คนเดียว (เจ้าของ) · ใช้จากไอโฟน Safari เป็นหลัก · ฟรีทั้งหมด
สถานะ: **ร่าง — เคาะแล้วเฉพาะข้อ 1-4 · ข้อ 5 เป็นต้นไปยังไม่ผ่านตาเจ้าของ**

## 1. เป้าหมาย

สมุดบันทึกการเดิมพันบอลส่วนตัว 1 คน ทำ 4 อย่าง:

1. คัดคู่จาก Forebet เฉพาะ **Featured match** กับ **Pick of the day** → การ์ดเตือน 2-4 ใบต่อวัน
2. ถ่ายสลิปส่งเข้าเทเลแกรม → อ่านด้วย OCR → บันทึกลงชีต
3. เปิดหน้า MY BET แคปหน้าจอไปแชร์ได้เลย
4. จบเกมตอบสกอร์ใต้ใบเดิม → คิดแฮนดิแคปเอง → ได้กำไร/ขาดทุน → ขึ้นหน้าบัญชี

**ไม่ใช่** ระบบทำนายผล ไม่ใช่ระบบหลายคน ไม่ใช่ระบบขาย ไม่มีล็อกอิน ไม่มีแชต

## 2. สถาปัตยกรรม (ทาง A — ห้องใหม่ทั้งหลัง)

```
Forebet ──(GAS ดูดเอง)──> ชีต PICKS ──> JSON ──> หน้า 1 FOREBET
                                                       |
สลิป ──> บอทใหม่ ──> GAS ──> Vision OCR ──> ชีต BETS ──> หน้า 2 MY BET
                              |                          หน้า 3 LEDGER
ตอบ "3-1 จบ" ──> GAS คิด AH ──+
```

- **GAS โปรเจกต์ใหม่** = หลังบ้านทั้งหมด (ดูด Forebet / รับเทเลแกรม / OCR / คิดเงิน / คาย JSON)
- **Google Sheets ไฟล์ใหม่** = ที่เก็บข้อมูลที่เดียว
- **GitHub repo ใหม่ + Pages** = หน้าเว็บ 3 หน้า อ่านอย่างเดียว ไม่มีคีย์อยู่ในนั้น
- **บอทเทเลแกรมตัวใหม่** = ทางเข้าสลิปกับทางตอบผล

**ไม่มี Python ไม่มี GitHub Actions** — เพราะ Forebet บล็อก IP ของ Actions (403) ตัวดูดต้องอยู่ที่ GAS อยู่ดี ตัดทั้งชั้นทิ้ง

## 3. กฎไม่ชนกับ PIKTAX (บังคับ)

| # | กฎ | ผลถ้าไม่ทำ |
|---|---|---|
| 1 | คนละบอท คนละโทเคน | สลิปบอลไหลเข้าบัญชีภาษี = ผิดกฎข้อ 3 |
| 2 | คนละ GAS project | ชื่อฟังก์ชัน/trigger ชนกัน |
| 3 | คนละไฟล์ชีต | ตัวเลขข้ามฝั่ง |
| 4 | ดูด Forebet ด้วย GAS ตัวเอง ห้ามเรียก `?ff=` ของ PIKTAX | PIKTAX ล่มแล้วลามมา |
| 5 | สร้างใหม่ให้ใช้ได้จริงก่อน แล้วปิด cron เก่า แล้วค่อยลบไฟล์ | มีช่วงว่างมือ |

`BetSlip.gs` `BetGate.gs` `BetRules.gs` `BetTeam.gs` ใน PIKTAX **ไม่แตะ ไม่ลบ** — คนละเรื่องกับ forebet และกฎข้อ 3 ยืนอยู่บนมัน

## 4. คีย์และความปลอดภัย

- โทเคนบอท / คีย์ Vision / ไอดีชีต อยู่ใน **Script Properties เท่านั้น** ห้ามเขียนลงไฟล์ ห้ามส่งมาในแชต
- หน้าเว็บบน Pages มีแต่โค้ดที่เปิดเผยได้ ดึงข้อมูลผ่าน URL `exec` ที่คายเฉพาะ JSON ที่ตั้งใจให้เห็น
- ไม่ส่งข้อมูลการเงินไปผู้ให้บริการ AI ที่ไม่เปิดเผยตัว

## 5. ท่อ Forebet ใหม่ (หน้า 1)

**เอาแค่ 2 ช่อง** — Featured match กับ Pick of the day · เลิกดูดทั้งตาราง

- GAS trigger วันละ 4 รอบ (07:10 / 13:10 / 19:10 / 01:10) ดูด `forebet.com` ตรงจาก IP ของ Google
- แต่ละรอบเก็บ: ลีก · ทีมเหย้า/เยือน · เวลาเตะ · ผลที่ Forebet เดา (1/X/2) · สกอร์ที่เดา · เปอร์เซ็นต์ · ราคาที่หน้าเว็บโชว์
- ลงชีต **PICKS** หนึ่งแถวต่อคู่ กันซ้ำด้วยกุญแจ `วันที่+ทีมเหย้า+ทีมเยือน`
- คายเป็นการ์ด **2-4 ใบต่อวัน** (มากกว่านั้นตัดทิ้งตามลำดับเปอร์เซ็นต์)
- **ดูดไม่ได้ = หน้าเว็บต้องไม่พัง** — โชว์การ์ดของรอบล่าสุดที่มี + ป้าย `ข้อมูลรอบ 13:10` และมีปุ่มกรอกมือ

ชีต PICKS: `ID, วันที่, ช่อง(FEATURED|PICKOFDAY), ลีก, ทีมเหย้า, ทีมเยือน, เวลาเตะ, เดาผล, เดาสกอร์, เปอร์เซ็นต์, ราคา, สกอร์จริง, ถูกผิด, สร้างเมื่อ`

**สถิติแยกกันคนละเล่ม**: PICKS = Forebet เดาแม่นแค่ไหน · BETS = เงินเข้าออกจริง สองอย่างนี้ห้ามเอามารวมเป็นตัวเลขเดียว

## 6. บิลย่อย (หัวใจของงานนี้)

หนึ่งคู่บอล = **1 บิลแม่ + บิลย่อยกี่ใบก็ได้** ทุกใบมีเงินของตัวเอง คิดแยก แล้วรวมเป็นยอดของคู่นั้น

ตัวอย่างที่เจ้าของยกมา — อองเซ กัลดาส Forebet เดา 1-1:

| ใบ | ตลาด | รายละเอียด | เหตุผล |
|---|---|---|---|
| แม่ | AH | อองเซ กัลดาส +0.5 @ 1.95 | รองนำก่อน |
| ย่อย 1 | OVER_UNDER | Over 1.5 | ต่อต้องไล่ = มีลูกเพิ่ม |
| ย่อย 2 | DRAW | เสมอ @ 6.161 | ไล่ทันพอดีตามที่เดา |

ตลาดที่รองรับ: `AH` · `OVER_UNDER` · `CORRECT_SCORE` · `DRAW`
วันอื่นใบย่อยเป็นอย่างอื่นได้ (เดา 1-1 ตรงตัว / Under 2.5) แล้วแต่จังหวะ — ระบบไม่คิดใบย่อยให้เอง **เจ้าของสั่งเอง** ระบบแค่เก็บ คิดเงิน และรวมยอด

ในชีต BETS ใช้คอลัมน์ `Parent_ID` + `Bill_Type`:
- บิลแม่ `Parent_ID` ว่าง
- บิลย่อยใส่ ID ของแม่
- หน้า MY BET โชว์แม่เป็นหัว ใบย่อยเป็นบรรทัดใต้ + ยอดรวมของคู่

## 7. สลิปเข้า → บันทึก

1. ส่งรูปสลิปเข้าบอท
2. GAS เรียก Vision OCR
3. แกะ: ทีมที่เลือก · คู่แข่ง · แฮนดิแคป · ราคา · ยอดเดิมพัน · เวลาเตะ
4. **ห้ามเดา** — อ่านไม่ครบให้ตอบเป็นคำเตือน แล้วรอเจ้าของพิมพ์เติม
   - `อ่านสลิปไม่ครบ` · `อ่านชื่อทีมไม่ชัด` · `ไม่พบยอดเดิมพัน`
5. กันลงซ้ำ 2 ชั้น: `Telegram_Message_ID` + กุญแจ `คู่+เวลา+ทีมที่เลือก+แฮนดิแคป+ราคา+ยอด`
6. ตอบสั้น: บันทึกแล้ว + ชื่อคู่ + ทีมที่เลือก + ราคา + ยอด

**กฎเหล็กข้อ 7 ของสเปก**: เก็บ `ทีมเหย้า` `ทีมเยือน` `ทีมที่เลือก` `คู่แข่ง` `แฮนดิแคป` `ราคา` แยกช่องกัน ห้ามโชว์แฮนดิแคปของฝั่งตรงข้ามเด็ดขาด

## 8. ตอบผล → คิดแฮนดิแคป

ตอบใต้ใบเดิม (reply) ว่า `3-1 จบ` หรือแค่ `3-1` → ระบบรู้ว่าใบไหนจาก `Telegram_Reply_To_ID`
ถ้าไม่ได้ reply ให้พิมพ์ `<Bet ID> 3-1`

**สูตรเดียวจบ** — ยึด "ส่วนต่างประตูของฝั่งที่เราแทง":

```
margin = (สกอร์ทีมที่เลือก - สกอร์คู่แข่ง) + แฮนดิแคป
```

| margin | ผล | ป้าย |
|---|---|---|
| `> 0.25` | ชนะเต็ม | WIN FULL |
| `= 0.25` | ชนะครึ่ง | WIN HALF |
| `= 0` | คืนทุน | PUSH |
| `= -0.25` | แพ้ครึ่ง | LOSS HALF |
| `< -0.25` | แพ้เต็ม | LOSS FULL |

รองรับ 0 · ±0.25 · ±0.5 · ±0.75 · ±1 · ±1.25 · ±1.5 (ลูกควอเตอร์แบ่งเงินครึ่งหนึ่งไปสองข้าง — สูตรข้างบนครอบให้แล้ว ไม่ต้องแยกเคส)

ตลาดอื่น:
- `OVER_UNDER` — ผลรวมประตูเทียบเส้น ควอเตอร์ใช้สูตรเดียวกัน
- `CORRECT_SCORE` / `DRAW` — ถูกคือชนะเต็ม ผิดคือแพ้เต็ม ไม่มีครึ่ง

## 9. คิดเงิน

| ผล | กำไร/ขาดทุน |
|---|---|
| WIN FULL | `เงิน x (ราคา - 1)` |
| WIN HALF | `เงิน x (ราคา - 1) / 2` |
| PUSH | `0` |
| LOSS HALF | `-เงิน / 2` |
| LOSS FULL | `-เงิน` |

ตรวจกับตัวอย่างในสเปก (300 @ 1.78): `+234` · `+117` · `-150` · `-300` ✅ ตรงทั้งสี่

เก็บลงชีตเป็น**ตัวเลข** ไม่ใช่ข้อความ · ยอดคืน = `เงิน + กำไร` (คิดตอนแสดง ไม่เก็บซ้ำ)
ยอดของคู่ = บิลแม่ + บิลย่อยทุกใบ

## 10. สามหน้าเว็บ

แถบล่างติดตาย `FOREBET | MY BET | LEDGER` · นิ้วโป้งกดถึงทุกปุ่ม · แตะได้ไม่ต่ำกว่า 44px

| หน้า | มีอะไร |
|---|---|
| 1 FOREBET | การ์ด 2-4 ใบของวันนี้ · เวลาเตะ + นับถอยหลัง · ปุ่มกรอกมือ |
| 2 MY BET | ใบเดิมพันไว้แคปแชร์ (ดูข้อ 11) |
| 3 LEDGER | กำไรสะสม + อัตราชนะ + **กราฟ เขียว=กำไร แดง=ขาดทุน** + รายการใหม่อยู่บน |

**หน้า 2 ห้ามโชว์**: บทวิเคราะห์ Forebet · สกอร์ที่เดา · เปอร์เซ็นต์ · เรื่อง OCR/เทเลแกรม/ชีต · Bet ID
**โชว์ได้**: คู่แข่ง · ทีมที่เลือก · แฮนดิแคป · ราคา · เวลาเตะ · นับถอยหลัง · สถานะ · สกอร์จบ

นับถอยหลังใช้ UTC+7 · เตะไปแล้วให้ขึ้น `สด` หรือ `จบการแข่งขัน` **ห้ามติดลบ**

## 11. หน้า 2 — ใบเขียวแบบจอดอส

เจ้าของสั่งเจาะจง ไม่ใช่ธีมรวม:

- พื้นดำ ตัวอักษรเขียวฟอสเฟอร์ ฟอนต์ monospace เส้นกรอบเป็นอักขระ
- ชื่อทีม**เป็นภาษาไทย** (ดูข้อ 12)
- **ลายน้ำคำว่า `Pickup` จางๆ พาดกลางใบ**
- ป้ายผล 4 แบบ + คืนทุน: เขียวเข้ม ✓ ชนะเต็ม · เขียวอ่อน ✓ ชนะครึ่ง · แดงอ่อน ✗ แพ้ครึ่ง · แดงเข้ม ✗ แพ้เต็ม · เทา คืนทุน

**ข้อขัดกันในสเปก แก้แล้ว**: ต้นฉบับข้อ 20 ห้ามหัวเขียวสว่างแบบเก่า — ตีความว่า **หน้า 2 เป็นดอสเขียวตามที่สั่ง ส่วนหน้า 1 กับ 3 เป็นดำ-พรีเมียม** ไม่ใช่เขียวทั้งแอป

## 12. ชื่อทีมภาษาไทย

- ตาราง `TEAMS` ในชีต: `ชื่ออังกฤษ | ชื่อไทย`
- แปลไม่เจอ = **โชว์ชื่ออังกฤษเดิม** ห้ามทับศัพท์มั่วเอง
- เติมชื่อได้จากมือถือด้วยคำสั่ง `/ทีม Once Caldas = อองเซ กัลดาส`
- แฮนดิแคป ราคา สกอร์ เวลา **ห้ามแปลง ห้ามปัด** ต้องตรงกับสลิปเป๊ะ

## 13. ปลดระวางของเก่า

ลำดับบังคับ — **สร้างใหม่ใช้ได้จริงก่อน แล้วค่อยแตะของเก่า**

1. ระบบใหม่รับสลิปได้ + คิดเงินถูก + หน้าเว็บขึ้น
2. ปิด cron 4 ตัวใน `football-scraper`: `fb-watch` `fb-value` `fb-cache` `fb-report`
3. เว้น 3 วัน ไม่มีอะไรพัง
4. **ค่อยลบไฟล์** — และต้องมีลิสต์ให้เจ้าของเคาะทีละบรรทัดก่อน (ลบแล้วไม่คืน)

**ห้ามลบเด็ดขาด**: `BetSlip.gs` `BetGate.gs` `BetRules.gs` `BetTeam.gs` ใน PIKTAX — กฎ "สลิปบอลห้ามไหลเข้าบัญชี" ยืนอยู่บนไฟล์พวกนี้ คนละเรื่องกับ forebet
